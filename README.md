# Profile

This project is a simple personal profile website.

## Files

- `index.html` — the main profile page
- `images/` — images used by the site

## Preview locally

Open `index.html` in a browser, or run a local static server from this folder if you prefer:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

This is a lightweight static site and can be customized by editing the HTML content and image assets.
